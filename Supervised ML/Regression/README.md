## 🚀 Implemented Algorithms

### 1. Ridge Regression (L2 Regularization)

Ridge Regression adds a penalty term to reduce large coefficient values.

**Key points:**

* Prevents overfitting
* Improves model generalization
* Works well when features are highly correlated

**Formula:**

```
Loss = RSS + λ(Σ coefficient²)
```

---

### 2. Lasso Regression (L1 Regularization)

Lasso Regression can shrink coefficients to zero, which helps in feature selection.

**Key points:**

* Performs feature selection
* Reduces model complexity
* Prevents overfitting

**Formula:**

```
Loss = RSS + λ(Σ |coefficient|)
```
